# Insight: Hover and airplane modes impose conflicting twist requirements

- slug: `wispy-sea-3682`
- kind: `insight`
- parents: `dry-hall-6882`

## Summary

The paper frames tiltrotor blade design as a compromise between hover and airplane modes because the twist distributions that improve one regime are not the same as those that improve the other.

## Notes

- Blade element reasoning in the paper identifies a lower modified-ideal twist for hover and a much higher modified-ideal twist for propeller mode.
- The conflict is strongest near the outboard region, where propeller-mode efficiency pushes for more twist while hover performance penalizes excessive loading.
- This conceptual conflict is the parent justification for both the single-point and multi-point experimental families.
